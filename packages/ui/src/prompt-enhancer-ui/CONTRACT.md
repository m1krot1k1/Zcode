# ui-prompt-enhancer

Интерактивные поверхности нативного улучшения промптов (`Enhance Prompt` / `/enhance`).

Инварианты:

- Кнопка и действие не вызывают модель сами: они работают через `usePromptEnhancer`, который
  получает `PromptEnhancerService` из `useServices()` (Local Host, SSH Server или Web Remote).
- Три состояния кнопки: `idle` (активна при непустом черновике), `enhancing` (клик = отмена),
  `undo_available` (возврат исходного черновика целиком, вместе с mention-чипами).
- Применение результата идёт через `editorApiRef.current.setText(...)`, то есть обычной
  программной заменой содержимого Lexical: шаг `Undo` остаётся у `HistoryPlugin`.
- В редакторах системных инструкций результат применяется сразу в целевое поле как
  черновик формы: промежуточного диалога «было/стало» нет, фиксация — только явное
  сохранение формы.
- `minDraftChars` различается для композера и системных инструкций; пустой ввод всегда
  оставляет кнопку неактивной.
- Ошибки не показываются как падение: отмена — нейтральное состояние, ошибка модели — короткий
  инлайн-текст без раскрытия содержимого черновика.
