## 6. Candidate recommendations

Формат: **problem/gap → ZCode evidence → proposed solution → scope/out-of-scope → expected effect → risks → complexity → priority → acceptance criteria → verification method**. Без сравнений с конкурентами.

### R-01. Убрать глобальный сброс фокуса, вернуть системные focus-индикаторы

- **Problem/gap:** `*:focus, *:focus-visible { outline:none!important; box-shadow:none!important }` уничтожает 274 ring- и 95 outline-фокус-стилей; базовый `Button` вообще не имеет focus-стиля. Keyboard-навигация визуально невидима, включая `forced-colors`.
- **Evidence:** `packages/ui/src/styles.css:126-139`; `packages/ui/src/components/ui/button.tsx:10-24`; воспроизведение probe2/probe5/probe7/probe8 (§8.5); `DESIGN.md:613-614`.
- **Proposed solution:** заменить глобальный reset на scoped-нормализацию: (а) убрать `!important` у `outline`/`box-shadow` для `:focus-visible`; (б) сохранить подавление системного outline только для `:focus:not(:focus-visible)`; (в) добавить в `buttonVariants` базу `focus-visible:outline-1 focus-visible:outline-ring` + `focus-visible:border-input-border-focused` (border-механизм доказанно работает) и/или перевести ring на `!important`-вариант; (г) в `forced-colors` вернуть `outline: 2px solid CanvasText`.
- **Scope:** `styles.css`, `button.tsx`, `tabs.tsx`, `select.tsx`, `checkbox.tsx`, `switch.tsx`, `radio-group.tsx`, `badge.tsx`. **Out of scope:** перерисовка фокус-стилей продуктовых компонентов.
- **Expected effect:** восстановление видимого фокуса на всех интерактивных элементах; соответствие `DESIGN.md:613-614`; закрытие high-contrast дефекта.
- **Risks:** возврат «жёлтой системной рамки» в Electron-окружениях (исходный мотив) — снимается `:focus-visible`-скоупом; возможны двойные рамки в composite inputs (`DESIGN.md:614` запрещает `!important` на потомках диалогов).
- **Complexity:** M. **Priority:** P0.
- **Acceptance criteria:** для `Button` (все 7 вариантов), `Input`, `Select`, `Tabs`, `Checkbox`, `Switch`, `RadioGroup` computed style при `:focus-visible` содержит либо непрозрачный outline ≥1px, либо box-shadow, либо изменённый border; в `forced-colors` — outline; ни один элемент с `:focus:not(:focus-visible)` не рисует системную рамку.
- **Verification method:** расширить Playwright-probe до component-matrix (сгенерировать HTML с классами примитивов, сфокусировать клавиатурой, снять computed styles); добавить e2e-тест «Tab по WorkspaceHeader → видимая рамка»; ручная проверка в desktop Electron на macOS/Windows/Linux.
