# Рой, OpenCode Go и локальные MCP-пресеты

## Цель

На ветке `dev` дать основному агенту настоящую вложенность субагентов, показать в OpenCode Go бесплатную модель `deepseek-v4.1-flash-free` и дать установить пять публичных MCP без секретов.

## Владелец

Глубину вложенности считает runtime, который создаёт child (`apps/zcode-cli/packages/core/src/runtime/methods/subagent.ts`). Порт субагента по-прежнему один: `createDefaultSubagentPort`. Второй очереди задач нет.

Каталог моделей остаётся в `config/provider/zcode-builtin.json`. Пресеты MCP — чистые данные в `packages/shared`; настройки только открывают уже существующую форму.

## Вложенность

Раньше child всегда получал `subagents.enabled: false`, а имена `Agent` и `Task` выкидывались из allowlist. Из-за этого рой обрывался на первом уровне.

Теперь глубина корня — 0. Child может породить своего child, пока его глубина строго меньше потолка. Потолок по умолчанию и абсолютный максимум — 64. `ZCODE_MAX_SUBAGENT_DEPTH=0` запрещает порождение даже корню. `1` возвращает прежнее поведение: корень порождает, child нет. Значение выше 64 режется до 64. Нечисло остаётся на умолчании.

Бесконечной рекурсии нет: это предохранитель от fork-bomb, а не квота провайдера. Workflow child по-прежнему создаётся со своим `subagents.enabled: false` и не получает этот путь.

## OpenCode

`deepseek-v4.1-flash-free` добавляется в шаблон `opencode-go-chat` (`https://opencode.ai/zen/go/v1`). Окно 200000 и выход 32000 взяты из каталога Cline для провайдера `opencode`. Ключ по-прежнему вводит пользователь (`OPENCODE` / api-key шаблона). Ответ 429 остаётся ограничением сервера: клиент его не снимает и не обходит сменой аккаунтов.

## MCP

Opt-in пресеты, без env и oauth: context7, chrome-devtools, playwright, duckduckgo-search, web-fetch. Команда `npx -y <пакет>`. Нажатие только заполняет форму; запись происходит после сохранения пользователем.

## Самоулучшение

`node scripts/self-improve-pr.mjs --apply` открывает отдельную ветку и pull request. Токен берётся из `GITHUB_TOKEN` или `GH_TOKEN`, а если их нет в окружении — из gitignore-файла `.env.local`. Скрипт не печатает секрет и не мержит.

## Релиз macOS

`pnpm release:macos -- minor|major|patch` поднимает версию корня, собирает dmg и zip для архитектуры этого Mac и создаёт GitHub Release на ветке `dev`. Тег `vX.Y.Z`. В `main` релиз не сливается.

## Что этот инкремент не делает

- Не мержит pull request и не пушит в `main`.
- Не снимает серверный ответ 429.
