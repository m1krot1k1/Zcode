# cli-tool-self-repair

Детерминированный модуль самовосстановления аргументов вызовов инструментов (`ToolCallSelfRepair`) и синтеза инструкций декомпозиции при усечении ответа по `maxOutputTokens` (`F-01`).

Инварианты:

- При `finishReason === "length"` (и эквивалентных `max_tokens` / `max_output_tokens`) `repairToolInput` **никогда** не запускает догадки по закрытию скобок/кавычек JSON и возвращает `skipped_due_to_truncation`, а `turn-model-step` эмитирует `TOOL_CALL_TRUNCATED_BY_MAX_TOKENS`.
- `repairJsonStringDeterministic` исправляет только замкнутые синтаксические огрехи (внешние markdown fences, trailing commas, неэкранированные управляющие символы внутри закрытых строковых литералов) и отклоняет оборванный/несбалансированный JSON.
- Защита от зацикливания ограничивает серию последовательных сбоев схемы на один инструмент `<= 2` попытками с точной дифф-подсказкой по полям схемы.
