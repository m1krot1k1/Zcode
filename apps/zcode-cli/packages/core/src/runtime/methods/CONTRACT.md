# cli-core-takeover-tools

Резервная модель перехвата обязана иметь те же инструменты, что основная: иначе она отвечает
текстом «что нужно сделать», и задача остаётся невыполненной при живом вызове.

不变量:

- Набор = `getTools(model)` минус `ToolSearch`/`DeferredToolCall`; наследует ограничения turn
  (allowlist, выключенные subagents, automation-границы).
- Вызов идёт через `executor.execute` вне turn-loop; ошибка инструмента — результат с
  `isError`, исключение не пробрасывается; текст результата усечён до 6000 символов.
- Раунд пишется в request-историю до следующего запроса, иначе основная модель его отбросит.
